## Getting Started

### Prerequisites
- Python 3.10+
- Git
- Docker (optional)

### Installation

```bash
git clone https://github.com/KinDR007/VictronMPPT-ESPHOME
cd MPPT
pip install -e .
```

### Running Tests

```bash
python -m pytest tests/
```

### Project Structure

- `src/` — Main source code
- `tests/` — Test suite
- `tools/` — Development tools
- `anticloud/` — Anticloud overlay
- `docs/` — Documentation
